# 本机软件停车面板

在 Windows 本机运行：

```powershell
python F:\paper01\robot-vln-latest\tools\desktop_estop.py --host 192.168.43.18
```

窗口中的红色按钮、空格和 Esc（窗口获得焦点时）只发送 `POST /api/estop {"on":true}`。程序没有运动控制或解除停车入口。窗口每 0.5 秒读取车端 `/api/state`，仅在安全节点最近 1 秒内回报 `estop=true` 且输出速度为零时显示软件停车已确认。如果使用了网页令牌，运行时附加 `--token <令牌>`；不要把令牌写入代码或提交到 Git。

该面板依赖本机与车载电脑的局域网、车载网页节点、ROS 2 安全节点和底盘驱动。断网、车载系统宕机或其他节点直接向 `/cmd_vel` 发命令时，面板不能保证物理停车。实地跟车前需要独立的实体断电或等效的硬件急停，并检查 `/cmd_vel` 只有一个经过验证的安全发布者。充电期间只测试软件停车锁定和状态回执。
